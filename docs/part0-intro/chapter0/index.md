# 第 0 章 协议与纸面演练

## 本章导读

> 本章说明本教程的定位与学习路径，建立贯穿全书的统一测量协议，并认识模拟器工具链能做什么、不能做什么。读完后，你应该能用模拟器输出填写一份字段完整的纸面实验底稿。

## 0.1 教程定位与学习路径

说明本教程与 hello-rocm、hello-gpu 的分工，以及“预测 → 实测 → 校准 → 决策”的学习闭环。

## 0.2 AMD GPU 硬件图谱

整理后续实验需要的算力、带宽、显存与互联参数，并注明参数来源。

## 0.3 统一测量协议

统一 token、GB/GiB、延迟与功耗口径，约定预热、重复次数、方差记录，以及校准集与留出集的划分。

## 0.4 模拟器工具链与能力边界

认识模拟器覆盖的性能、显存、排队与通信建模范围，区分已支持与待补齐的能力。

## 0.5 纸面实验底稿

用模拟器输出填写一份实验底稿，确认硬件版本、软件版本、预热次数、重复次数与留出配置等字段完整。

- 本章目前是 Alpha 阶段的大纲骨架，正式正文会在对应实验跑通后补齐。
- 与本章相关的代码、实验配置与测量记录会放在 `code/part0-intro/chapter0/`。
