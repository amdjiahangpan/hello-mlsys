## 本章导读

> 本章说明本教程的定位与学习路径，建立贯穿全书的统一测量协议，并认识模拟器工具链能做什么、不能做什么。读完后，你应该能用模拟器输出填写一份字段完整的纸面实验底稿。

## 教学目标

- 能说明本教程与 hello-rocm（跑起来）、hello-gpu（算子做快）、MLSys·im（系统建模）的分工，并复述"预测 → 实测 → 校准 → 决策"的学习闭环；
- 能列出目标 AMD 卡的算力、显存带宽、显存容量与互联参数，并注明参数来源；
- 能执行统一测量协议：token / GB-GiB / 延迟 / 功耗口径，预热、重复次数与方差记录，校准集与留出配置的预先划分；
- 能说清模拟器工具链能建模什么（性能、显存、排队、通信）、不能建模什么，以及缺项时最小教学分析模型的定位；
- 能填写一份字段完整的纸面实验底稿（硬件版本、ROCm 版本、预热次数、重复次数、留出配置）。

## 内容梗概

### 教程定位与学习路径

本教程聚焦 LLM 推理系统：hello-rocm 教你跑起来，hello-gpu 教你把算子做快，MLSys·im 提供系统建模方法与工具，本教程教你用模拟指导系统设计，并在 AMD 真机上验证和校准。训练显存、算子调优与集群调度平台作为选读。全书每一章围绕同一个学习闭环展开：

> 定义场景与约束 → 运行模拟器并留存预测 → 选择实测点 → AMD 真机验证 → 解释误差与校准 → 留出验证 → 设计决策

### AMD GPU 硬件图谱

整理 T1–T4 教学档位与本教程实验需要的算力、带宽、显存与互联参数，并注明参数来源。主线真机为 RX 9070 XT 16 GB；W7900D 基线的型号、显存与单/双卡数量待资源方确认后回填。每个实验标注适用档位与无设备替代路径（仅 CPU 预测 / 云端）。

### 统一测量协议

统一 token、GB/GiB、延迟与功耗口径；约定预热、重复次数、随机种子与方差记录；记录软件版本与拓扑；校准集与留出配置预先分开，不能先看测试答案再回填参数。全书实验共用 predict / measure / compare 四类入口与同一份实验底稿模板。

### 模拟器工具链与能力边界

以 MLSys·im 的系统建模方法与固定版本为主，缺项使用最小、可解释的教学分析模型补齐。认识模拟器覆盖的性能、显存、排队与通信建模范围，区分已支持与待补齐的能力；未核实项不写成上游已支持。

### 纸面实验底稿

用模拟器输出填写一份实验底稿，确认硬件版本、软件版本、预热次数、重复次数与留出配置等字段完整。这份底稿模板将在后续所有真机实验章复用。

## 实验设计

### 模拟器实验

用第 1 章的模拟器输出填一张纸面实验底稿，确认字段完整（硬件版本、ROCm 版本、预热次数、重复次数、留出配置）。

### 真机实验：无

本章不使用真机；模拟器输出用于填写底稿，真机验证自第 2 章开始。

### 闭环与交付

- **预测（测前留存）**：模拟器输出与底稿字段。
- **实测（选点运行）**：本章无。
- **校准（解释误差）**：本章无；第 2 章产生第一条校准记录。
- **决策（提交）**：一份字段完整的纸面实验底稿，作为后续各章实验底稿的模板。
