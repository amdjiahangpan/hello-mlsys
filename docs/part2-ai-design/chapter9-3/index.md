# 第 9.3 章 负载启发的推理集群设计

## 本章导读

> 本章是全书的结营章：从固定应用与请求 trace 出发，在成本、能耗与容错约束下设计多机推理集群。先用模拟器完成设计与筛选，在资源允许范围内验证组件或子集，明确区分实测与外推。

## 教学目标

- 能用模拟器预测给定负载 trace 下集群的容量与拓扑需求；
- 能按成本（每美元有效吞吐）与能耗（每焦耳有效吞吐）比较多个集群方案；
- 能给出容错方案并说明其代价；
- 能在设计文档中区分"实测验证"与"模拟外推"，并把决策过程写进决策日志。

## 内容梗概

### 负载与约束

固定应用、质量评测集与请求 trace；SLA、成本预算与能耗目标。

### 容量与拓扑

模拟满足 SLA 所需的机器数与并行配置，比较不同拓扑。

### 成本与能耗

计算每美元 / 每焦耳有效吞吐，比较方案。

### 容错

节点失效对 SLA 的影响与冗余代价的取舍。

### 验证边界

在资源允许范围内验证组件或子集；明确区分实测与外推。

## 实验设计

### 模拟器实验

模拟容量、拓扑、成本、能耗与容错方案，用已校准的模型筛选候选集群设计。

### 真机实验（资源允许范围内）

在资源允许范围内验证组件或子集（如通信路径、单机服务组件）。无集群资源时本章以模拟器完成，并明确标注外推边界。

### 闭环与交付（与 AI 一起设计，结营）

- 学员和 AI 提出集群设计方案，先通过模拟器筛选，再对选定的子集实测（如有资源）。
- **提交**：设计文档（容量、拓扑、成本、能耗、容错）、每美元 / 每焦耳有效吞吐与决策日志；每个数字注明实测 / 外推范围。
