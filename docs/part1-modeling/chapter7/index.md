## 本章导读

> 本章从单次推理走向在线服务：请求会排队，延迟有分布，SLA 由尾部决定。读完后，你应该能预测并实测出"SLA 即将被突破"的并发水位。

## 教学目标

- 能定义 TTFT、TPOT / ITL 与端到端延迟，并说明 P50 / P95 / P99 在 SLA 中的作用；
- 能说明并发数与吞吐的关系、排队拐点的成因，并区分 batch 大小与在线用户数；
- 能用模拟器预测 P99 随并发增长的曲线，并标出 SLA 水位；
- 能用压测工具实测 TTFT / TPOT / P99 曲线，并对比预测与实测拐点。

## 内容梗概

### 服务延迟指标

定义 TTFT、TPOT / ITL 与端到端延迟。

### 分位数与尾延迟

理解 P50、P95、P99 在 SLA 中的作用。

### 并发、吞吐与排队拐点

理解并发数与吞吐的关系，以及排队拐点的成因；区分 batch 大小与在线用户数。

## 实验设计

### 模拟器实验

给定服务时间分布和到达率，模拟器预测 P99 随并发增长的曲线，标出"SLA 即将被突破"的并发水位。

### 真机实验（RX 9070 XT 16 GB 主线，单卡完全够用）

- 用 vLLM 或 llama.cpp server 启动一个可服务模型（Qwen3-4B）；
- 用 `vllm bench serve` 或 `servebench` 扫并发（1, 2, 4, 8, 16…），输出 TTFT / TPOT / P99 曲线；
- 找到 P99 开始陡升的并发点，和模拟器预测的拐点对比；
- 误差来源：显存不足导致 KV Cache 换出 / 抢占、Continuous Batching 的调度延迟、单卡算力饱和。这些都是真实的服务误差，不是模拟器能完全预测的。

### 闭环与交付

- **预测（测前留存）**：P99 随并发变化的曲线与 SLA 水位。
- **实测（选点运行）**：并发扫描的 TTFT / TPOT / P99 实测曲线。
- **校准（解释误差）**：预测与实测拐点的对比，误差归因（KV 抢占 / 调度延迟 / 算力饱和）。
- **决策（提交）**：TTFT / TPOT 分位数、P99 与失败 / 超时的预测与实测对照。
